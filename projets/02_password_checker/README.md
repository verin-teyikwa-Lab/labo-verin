outils soc pour tester la robustesse des mots de passe.
80% des piratages viennent de mots de passe faibles.
- python + module re ( expressions regulieres)
- systeme de scoring sur 5 critetres ANSSI
- 8 caracteres, Majuscule, minuscule, chiffre, special

- 5/5 = FORT (vert)
- 3-4/5 = MOYEN (orange)
- <3 = FAIBLE (rouge) = Danger

cet outils montre ma capacite a faire de la prevention et de analyser des logs avec regex,
